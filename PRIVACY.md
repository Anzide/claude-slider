# Privacy policy

Claude Slider does not collect, store, or send any user data.

- It runs only on `claude.ai`, where it adds sliders and operates the page's own model menu.
- It makes no network requests and has no server.
- It saves one item in the page's `localStorage` on your own computer: the list of model and effort names from the menu, and which Claude Code sessions have the Ultracode switch. This never leaves your browser.
- It uses no analytics, ads, or third-party services.

Questions: open an issue at https://github.com/Anzide/claude-slider/issues.
